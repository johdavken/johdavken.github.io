Guide
Quick StartSet up Resin.Tools in just a few minutes

Resin.Tools can be set up in just a few minutes.

  1. Set the changeover deadline, enter the line rate, and select the layer count.
  2. Verify the receiver hopper weights.
  3. Build the layer recipe on the Recipe Setup page.
  4. Turn on tracking for the hoppers involved in the changeover.
  5. Open the Timeline to see when each hopper should begin running down.
  6. Use Production Summary at the end of the run to total material usage for inventory.
SetupPrepare the line and timing inputs
  1. Under Current Changeover, set the deadline, enter the current line rate, and select the layer count.
  2. Use the ☰ menu at the right of the status bar to choose the theme, surface style, timeline style, view density, and time format.
  3. Open Receiver hopper weights and enter the usable pounds held by each hopper. Accurate weights are required for useful run-down times.
  4. For faster weight entry, select individual cells, click a hopper number to select its row, or click a layer heading to select its column. Enter one weight above the matrix and apply it to the selection.
  5. Choose whether receiver hoppers use numbered labels or Main + 1–5 labels. On mobile, this control is available in Advanced mode.

Heads up: Changes save to this browser immediately. Setup warnings identify missing weights or other inputs that reduce timing accuracy.

Recipe SetupBuild the layer and resin recipe
  1. Enter the percentage of total output assigned to each layer. The layer percentages should total 100%.
  2. Enter or choose a resin name in every active hopper's empty resin field.
  3. Enter hopper percentages in hoppers 2–6. Hopper 1 is calculated automatically as the remaining percentage so each layer totals 100%.
  4. Use the clock button beside a hopper to include it in the Timeline. Bulk-selection checkboxes are separate and appear only in Bulk Edit mode.
  5. Use a layer's Copy button when another layer uses the same resins and hopper percentages. Copy does not change the destination layer percentage.

Using Bulk Edit

  1. Turn on Bulk Edit.
  2. Select cells individually, a numbered row, a layer column, or all hoppers.
  3. Enter a resin name, a hopper percentage, or both in the bulk fields.
  4. Select Apply. Resin names apply to every selected cell; percentages apply only where editable and are rejected if they would push a layer over 100%.
  5. Use Reset all to empty every resin field and clear hopper percentages, tracking, and pump-off states before building a recipe again.

A problem message appears below a layer only when its hopper percentages need attention.

TimelineFollow hopper changeover timing
  1. Only hoppers with their clock tracking button enabled appear in the timeline.
  2. With a changeover deadline set, entries are sorted by the time each hopper should begin running down. Without a deadline, they are sorted by time to empty.
  3. After physically turning off a hopper pump, mark Pump off. Completed hoppers are hidden unless Show all is enabled.
  4. Use Reset tracking at the appropriate time to untrack every hopper and clear pump-off states.

On mobile, select Timeline beneath the Resin.Tools logo to hide every other section and keep only the timeline and production footer visible.

The footer on mobile shows the next tracked hopper and current RT Sync status.

RT SyncShare a production line across devices
  1. Create one permanent line workspace on the first device and give the device a recognizable label.
  2. Generate a four-character link code. On another device, open RT Sync, enter that code, and select Join RT Sync.
  3. On phones, RT Sync is simplified around the current line, device label, sync details, Refresh, Disconnect, and Leave. Line creation, naming, link-code generation, and device administration remain on desktop.
  4. Watch the status and unsynced-change count. Local changes save first, then upload; other connected devices update without a page refresh.
  5. Disconnect on this device pauses syncing but keeps membership. Leave RT Sync removes that device's membership.
  6. New job clears current job inputs and tracking while preserving the line workspace, linked devices, Saved Line Settings, and hopper weights.

Link codes are one-time codes that expire after 30 minutes. The owner must transfer ownership before leaving and is the only device allowed to remove members or delete the shared line.

Line ConfigurationsSave and restore common line setups
  1. On mobile, open Advanced mode first. Enter a configuration name and choose Save / Update config to capture the current complete setup.
  2. Select a saved configuration and choose Load to replace the active inputs with that setup.
  3. Use Rename or Delete to maintain the list. When RT Sync is connected, these changes are shared with the line.
  4. Export copies a configuration as JSON. Import validates pasted JSON before saving it and can optionally load it immediately.
ToolsProduction calculators and resin reference

Select a utility from the tool index. Resin.Tools displays one tool at a time to keep the workspace focused and reduce scrolling.

  • Production Summary: Build the active recipe first, then enter production and scrap pounds to calculate material totals by resin for production reporting and inventory issuance.
  • Short Footage Calculator: Enter actual weight, target footage, and the last good weight to calculate adjusted short footage.
  • Hopper Weight Calculator: Enter hopper circumference and usable height, then provide bulk density directly or estimate it from polymer density and the adjustable packing factor.
  • Resin Lookup: Search by resin code or description. Select a suggestion to view description, density, material information, and typical uses. The Copy button copies the numeric density.
