How Smart Hoppers work

Smart Hoppers automatically uses cylindrical dimensions (shared hopper circumference and each hopper’s usable height) or known usable volume, whichever method the connected line uses, together with the assigned recipe resin’s measured bulk density. Manual weights remain available at all times. Smart Hoppers requires a connected workspace with an identified line.

Using the Timeline

Timeline

Lists your tracked hoppers, soonest pump-off first. Track hoppers on the Recipe screen and they appear here. Show all also lists hoppers already pumped off; Reset tracking untracks every hopper. Turn on the alarm to be alerted when a pump-off is due while Resin.tools is open.

Hookups

On the Hookups tab, set where each resin feeds from — silo or box line. Those short source labels then show inline on each Timeline row (A0700 [A] → A0711 [C]). Saved automatically and shared over RT Sync.

Options

The gear beside Show all opens Timeline Display: show or hide the Next resin on each row, and choose whether source labels appear for Current or Current + Next. Saved on this device.

Connecting to RT Sync

Connect this device to the workstation for the production line you are running.

At the line workstation

1. Open RT Sync

Open RT Sync on the desktop assigned to your production line.

2. Make sure the desktop is connected

If the desktop shows “This desktop is not connected,” select CONNECT THIS DESKTOP and connect it to the correct line first.

3. Generate a link code

Under Connect Another Device, select GENERATE NEW CODE.

The workstation will display a temporary four-character code and QR code.

On this device

4. Join the line

Either:

  • Scan the QR code shown on the workstation with your phone camera
  • or enter the four-character code in Link code and tap Join RT Sync
5. Confirm the connection

RT Sync should show Synced and display the production line you joined.

Good to know

Link codes are one-time codes and remain available for 30 minutes. Generate another code from the workstation when connecting another device.

    What’s new, most recent first

    (v1.1.24) (September 1-3, 2026) - Desktop Dashboard, Station Console & Workspace Management

    • New desktop-only Dashboard overview (sidebar foot or RT logo): line, changeover time, output, next hopper action, and RT Sync status at a glance. Back to Line restores the prior section without changing the active workspace.
    • Station Console: a consistent flat, chip-style button treatment now covers every desktop toolbar — Recipe/Weights, Recipe and Timeline tabs, Timeline, RT Sync, Tools, Sudo Access, Dashboard, and the changeover wizard — and extends to tablets as well.
    • Redesigned Workspace Management into a desktop master/detail view, with the workspace browser staying visible beside a selected line’s devices and controls.
    • Tools panel unified: every desktop tool shares one header/description/help-icon layout, and all info icons (Tools and Timeline) now use the same glyph. Resin Database’s search no longer shifts the panel, and Add resin now sits beside a narrower search field.
    • Recipe grid: the cross-resin overlay toggle is now a paired-pages icon instead of an eye, and hopper tracking shows as a small clock on the hopper badge instead of a folded-corner check.
    • Timeline: hoppers missing a receiver weight now collapse into one compact NEEDS WEIGHT group instead of separate rows; fixed Hookups grouping so a partially-sourced resin shows Mixed instead of falsely appearing fully assigned.
    • Two new themes, Newsprint and Ayu Light; several existing theme accents refined; Evergreen Light retired (existing selections fall back to Evergreen).
    • Continued flattening the desktop workspace: quieter panel surfaces, a hairline production status bar, and Line Configuration matching the flat list treatment already used elsewhere.
    • Desktop side-rail: the More pill previews its foldaway sections as a small icon strip, and Display settings gains a Side Rail Style choice (filled or underlined active row).

    (v1.1.23) (August 28-30, 2026) - RT Cloud, Line Configuration & mobile workflow polish

    • Refined Recipe → Weights on mobile: bulk Weight/Height controls now use the same compact inline editor pattern as Current and Next, directly above the hopper matrix. The large lower editor card is gone; selection status now sits subtly below the matrix.
    • With Smart Hoppers off, mobile hopper cells now show pounds only and the bulk editor shows only Weight. Smart Hopper height/volume details return when enabled, and the manual-only summary readout no longer clips.
    • Added the neon Vaporwave display theme for mobile and tablet. OLED Black, Vaporwave, and Rosé Pine Dark are now touch-only display choices, while a saved preference resumes when returning to a touch layout.
    • New RT Cloud option in RT Notes → Backup: an optional, private, end-to-end encrypted recovery backup of your whole notebook. Enable it once and you get an RT Cloud Recovery Code; edits back themselves up in the background. If the app is reinstalled or its data cleared, Restore from RT Cloud with that code brings everything back.
    • This is recovery, not sync. Your notes never appear on another device on their own, RT Cloud is never linked to a workspace or an RT Sync device, and the backup is encrypted on your device - RT Cloud cannot read note text, titles, or folder names. Turn it off (keeping the backup) or delete the cloud backup entirely at any time.
    • Added an administrator-only Line Configuration manager under Sudo Access. Lines 1-15 are preloaded with their existing layer count, Layer A orientation, Smart Hopper geometry, and hopper naming behavior; administrators can add aliases, update those settings, deactivate definitions, or add future lines without another hard-coded app release.
    • Line behavior now resolves from one shared definition, preferring a workspace’s structured line number, then configured names and aliases, while preserving exact legacy Line N matching. Definitions are cached locally and retain built-in defaults, so known lines keep working during a network outage. Unsupported future layouts, such as a configured seven-layer line, are recognized without being silently downgraded.
    • Added Determine Changeover Time on mobile and desktop: enter line speed, footage per roll, number-up, active winders, time left on the current set, and rolls remaining to estimate the changeover. Review or adjust the answers, then apply the estimated time through the existing synced Changeover field.
    • Updated the web, PWA, iOS Home Screen, and Android launcher icons to use the existing five-layer Layer Stack mark without RT lettering, recolored in the active Rosé Pine Light palette.
