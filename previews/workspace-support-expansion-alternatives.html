Workspace & support — expansion redesign, 6 directions

Same five rows in every column (RT Sync, Tools, Request beta access, Changelog, Sudo access) with their real icons, copy and per-section accent colours. Each direction is a genuinely different structure, not a recolour of the current list. Changelog is shown in its open/active state in every concept so that treatment can be compared too.

1Grouped inset card

All five rows live inside one bordered card instead of loose dividers running to the screen edge - reads as a single settings section, and the enclosing edge does the separating work the full-width hairlines used to.
