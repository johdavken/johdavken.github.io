Fold cover recipe grids

Ten layouts for the Home recipe grid on the folded Galaxy Z Fold 8 cover screen (412 × 900 CSS px). Each design is shown for a 5-layer line and a 3-layer line, with identical cell sizes in both. The 3-layer grid keeps the same column width and centres itself instead of stretching.

The 5-layer data is the Line 10 job from your screenshot. The 3-layer job is made-up example data built from layers A, C and E. The status bar, sync pill, toolbar and footer stay the same across designs so only the grid is compared.
