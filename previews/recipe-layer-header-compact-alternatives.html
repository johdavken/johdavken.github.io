Recipe layer header — 6 more compact directions

Wide desktop (>1200px) renders each layer header as a 64px watermark letter plus percentage plus total — about 93px tall measured live, before a single hopper row starts. Tablet width (701–1200px) already replaced this with a small inline letter next to a dominant percentage — about 51px — but that treatment was never carried up to wide desktop, which is what today's screenshot shows. These six explore how much further that can go, all still built from .splitLayerTitle / .splitLayerPct / .splitColumnTotal - same data, no hopper-row changes below.

Values mirror the screenshot: Layers A–E, MS0400 in A/B/C, running totals of 100%. Height tags are the approximate rendered height of one header cell.
