Clear Tracking: icon candidates

Each row mock is the real 4-slot bar (Scan / Load Next / Clear Tracking / Print) at native size, so the candidate can be judged next to the icons it will actually sit beside. Load Next stays text for now since only Clear Tracking's icon is in question.

01EraserGeneric "clear"
Load Next
Reads as "erase/undo" in general software, but carries no connection to tracking specifically - an operator could just as easily read it as "clear the recipe" or "undo".
02Eye, slashed"Stop watching"
Load Next
Widely understood as "hide/don't watch" (password fields, visibility toggles). Reasonably close to tracking's meaning, but tracking here is really "flagged for the timeline", not "visible" - a slight metaphor mismatch.
03Marker pin, slashedMatches the actual badge · recommended
Load Next
A tracking mark IS a pin/badge dropped on a hopper - this is the one candidate that mirrors what's actually being removed rather than a generic UI verb. Reads as "remove the marker", which is exactly the action.
04Target, slashed"Tracking" as targeting
Load Next
Leans on "tracking = targeting", a more surveillance/military metaphor. Legible once you know the app, but the concentric-circle shape reads closer to "location/GPS off" than to a hopper flag.
05Circular reset arrow"Reset" not "clear"
Load Next
Instantly readable as "reset/refresh" - but that's a problem here, not a strength: it invites confusion with Timeline's separate Reset tracking control, which does something broader (drops pump-off state too).
06Flag, slashed"Unflag"
Load Next
"Flag" is a common review/bookmark metaphor, but not one this app uses anywhere else for tracking - it would be introducing a new visual vocabulary rather than reusing an existing one.

My lean: #3, the slashed marker pin. It's the only option that visually mirrors the thing being removed - the badge a tracked hopper actually gets - rather than borrowing a generic "clear/reset/hide" verb from elsewhere. #2 (eye-slash) is the safer fallback if #3 reads as too small/detailed at 18px; #5 (reset arrow) I'd avoid specifically because Timeline already has a differently-scoped "Reset tracking" action, and the same icon on two different-behaving buttons is the kind of ambiguity this app's philosophy explicitly warns against.
