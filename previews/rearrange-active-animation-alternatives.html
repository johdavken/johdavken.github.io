Rearrange: animated active states

Five motion treatments for the latched Rearrange control. Every candidate keeps the current two-arrow glyph (left down, right up) and the 55% accent fill already on the live button — only the motion while the mode is on changes. Idle is the static muted icon; click any Rearrange control to toggle.

Mocked in the real mobile six-control rail (Undo / Redo / Clear / Empty / Rearrange / Reset) plus the labeled desktop/tablet chip, so the motion is judged at the size it will actually occupy. Animations pause under prefers-reduced-motion.

This browser is asking for reduced motion, so the loops below are frozen on the latched fill. Turn that setting off to compare the animations.

01Opposing travelContinuous shuttle
Recipe · Edit toolbar
Left arrow rides down while the right rides up, then they reverse — the most literal “alternating up and down.” Always in motion, so it is hard to miss and a little busy next to static siblings.
Best if the goal is maximum “this mode is on” at a glance. Risk: a production-floor loop that never rests can start to feel like a loading spinner.
02SeesawSame shuttle, with overshoot
Recipe · Edit toolbar
Same opposing travel as 01, but the easing overshoots at each end so the pair rocks rather than glides. Slightly more “alive,” slightly less mechanical.
Use this if 01 reads as a progress spinner and you want the same idea with a bit of bounce. Still always-on motion.
03Traveling headsShafts hold, chevrons run
Recipe · Edit toolbar
The two shafts stay planted (so the glyph doesn’t jitter in the 40px cell). Only the arrowheads run the length, out of phase, and fade at each end — more “content is moving” than “the button is bouncing.”
Closest to a conveyor / hopper-to-hopper reading. Idle (click to toggle) still shows both heads parked, so the static icon remains the same two-arrow mark.
04Half-turn swapDirections invert, then hold
Recipe · Edit toolbar
The whole pair rotates 180°, rests, rotates again. Down becomes up, then back. Reads as “these two things are swapping,” which is the actual rearrange action.
Quiet between turns, so it spends most of its time looking like the current latched icon. The flip is the cue. Watch whether the 40px cell makes the rotation feel like a refresh spinner — it shouldn’t, because it holds at each pole.
05Staggered tickMostly still
Recipe · Edit toolbar
Left arrow takes a short dip, rests; right arrow takes a short lift, rests. A 3.2s loop that is still most of the time — a metronome, not a spinner.
The production-floor pick if motion should remind, not occupy. Easy to miss on a glance; very unlikely to compete with the matrix. Closest in spirit to the current static latch, with a periodic nudge.

All five keep the live latch (55% accent fill, title-colored stroke) and the existing glyph. Nothing here is wired into the app — this page is only for picking a motion. Click any Rearrange control to compare idle vs active; Pause all motion freezes every loop on the latched pose.
